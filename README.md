# Aurora OS

A portable operating system for high-performance gaming.

## Status

Early development — boot and VGA.

## Stack

- **C** — drivers and interop
- **Rust** — kernel core, memory, scheduler
- **Assembly** — boot, context switch

## Roadmap

- [x] Initial structure
- [ ] Boot (Limine/Multiboot2)
- [ ] VGA text mode
- [ ] GDT / IDT
- [ ] Physical and virtual memory
- [ ] Scheduler
- [ ] Syscalls
- [ ] Userspace
- [ ] Drivers
- [ ] GPU (long term)
